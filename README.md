# Manuscrito — Downloads e Beta

Este é o repositório público de distribuição do **Manuscrito**, um aplicativo desktop voltado à escrita e organização de projetos literários e de roteiro.

> Este repositório contém apenas materiais públicos de distribuição, documentação de teste e notas de versão. O código-fonte de desenvolvimento não é publicado aqui.

## Beta multiplataforma

A fase beta será disponibilizada progressivamente para:

- Windows x64;
- macOS Apple Silicon;
- macOS Intel;
- Linux x64 (AppImage e Debian).

Os builds de macOS e Linux devem ser considerados **experimentais** até passarem por testes em máquinas reais.

## Downloads

Os instaladores aprovados serão publicados na seção **Releases** deste repositório. Evite baixar executáveis enviados por terceiros ou hospedados fora deste canal.

## Como participar dos testes

1. Baixe a versão correspondente ao seu sistema na página de Releases.
2. Leia as instruções específicas do sistema.
3. Execute o checklist em `BETA_CHECKLIST.md`.
4. Ao encontrar um problema, registre sistema operacional, versão do Manuscrito, passos para reproduzir, resultado esperado, resultado obtido e, quando possível, print ou vídeo.

## Segurança e assinatura

Durante o beta, alguns sistemas podem exibir avisos de segurança porque os pacotes ainda podem não possuir assinatura/notarização comercial. As notas de cada Release informarão o estado de assinatura de cada plataforma.
